# 图片目录

README 里的截图请放在这里，例如：

- `screenshot-collapsed.png` —— 折叠态：每条助手回复上方的用量胶囊
- `screenshot-expanded.png` —— 展开态：逐次模型请求明细（含重试）

放好后把 `README.md` / `README.en.md` 中「截图 / Screenshot」一节的 TODO 替换成：

```markdown
![折叠态](./docs/screenshot-collapsed.png)
![展开态](./docs/screenshot-expanded.png)
```

建议宽度 1000px 左右，浅色或深色主题均可（插件只使用主题 token，两者都自适应）。
