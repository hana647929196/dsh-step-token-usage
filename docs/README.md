两张都是 1824×2299 左右的整窗截图，约 285 KB / 张，保持原分辨率以便放大看清小字（未压缩、未裁切）。

## 补充截图时的建议

- 插件只使用主题 token，**浅色与深色主题都自适应**，两种主题的截图都欢迎。
- 整窗截图在 GitHub 上会被缩到内容列宽度（约 880px），小字需要点开查看。若要更醒目，可以裁到「胶囊 + 展开面板」这一块再提交。
- 如果重命名文件，记得同步改上面两处引用。
